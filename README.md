## 🚀 Мои проекты

### 🎯 FovoritItems — RPG-ядро для Paper
> Комплексный плагин с кастомными предметами, магазином за PlayerPoints, аукционом, питомцами, маунтами и прокачкой предметов.

**Возможности:**
- ⚔️ Кастомные предметы со способностями (поджог, взрыв, молния)
- 👹 Кастомные мобы с настройкой HP, урона и дропа
- 🐺 Питомцы с реальным ИИ (Pathfinder API)
- 🐴 Маунты с ускорением
- 🏛️ Аукцион между игроками за поинты
- 📈 Уровни предметов и система статистики
- 🗄️ Поддержка MySQL через HikariCP

`Java` `Paper API` `Gradle` `PlayerPoints` `MySQL` `HikariCP`
